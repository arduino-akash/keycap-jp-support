Frequently asked questions

Why does the keyboard need "Full Access"?
Full Access is required because Keycap Jp calls the DeepL translation API over the network. Without it, iOS blocks keyboard extensions from making network requests, so the keyboard falls back to plain typing with no translation.

Do I need my own DeepL account?
No — Keycap Jp works out of the box with no signup. If you'd like higher usage limits, you can optionally add your own DeepL API key in Settings.

Is my typed text stored anywhere?
Translation history and pinned phrases are stored locally on your device (in a shared App Group container used by the app, keyboard, and share extension) so they can be viewed across all three. They are not uploaded to any server by Keycap Jp beyond the text sent to DeepL to be translated.

How do I enable the keyboard?
Open Keycap Jp → Setup tab → follow the on-screen steps to add the keyboard and enable Full Access under iOS Settings → Keyboards.
